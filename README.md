## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/illusion4044/BusinessProject.git
```

### 2. Install dependencies
```bash
npm install
```
## Run the Application

Start client:
```bash
cd client

npm run dev
```

Start server:
```bash
cd server

npm start
```

but, text me, you need .env file for running server
